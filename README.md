# Burger Boys: website

Guilt-free pleasures. 100% plant-based. 100% delicious.

A static, fast site built with **Vite 6 + TypeScript**, **GSAP/ScrollTrigger**, and one lazy **Three.js** scene.

## Run it
```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # typecheck + production build → dist/
npm run preview    # serve dist/ on :4173
npm run lint && npm run format
```

## How it's put together
| Path | What |
| --- | --- |
| `src/content/menu.ts` | **Single source of truth** for every item, price (integer cents), combo rule and anatomy copy |
| `src/content/images.ts` + `images.json` | Responsive `<picture>` helper; the manifest is generated by `npm run images` |
| `src/render/page.ts` | Build-time renderer. `vite.config.ts` injects the full markup into `index.html` |
| `src/ts/bag.ts` | Bag drawer: quantities, combo toggle, dip/drink choice, totals, focus trap, **demo checkout** |
| `src/ts/combo.ts` | Combo builder (burger + Good Mood Fries + dip + drink = burger + €3,95) |
| `src/ts/menuStage.ts` | Editorial menu stage with a circular photo wipe |
| `src/ts/anatomy.ts` | Ingredient chips (tap/click/keyboard), so the anatomy works without scrolling |
| `src/ts/motion.ts` | All GSAP choreography in `gsap.matchMedia()` (desktop / mobile / reduced motion) |
| `src/ts/hero3d.ts` | Three.js depth-parallax hero. Lazy, fine-pointer only, falls back to the still photo |
| `scripts/` | Image pipeline, anatomy layer cutter, depth map, icons, font subsetting, OG template |
| `assets-src/` | Full-quality image masters (not shipped) |
| `docs/` | `upgrade-audit.md`, `assets.md`, `handoff.md` |

### Changing a price or adding an item
Edit `src/content/menu.ts` only. The markup, combo builder and bag all read from it.

## Honest demo states (until real services exist)
- **Checkout** is labelled *demo*. It never claims an order was placed or charged.
- **Newsletter**: there's no form. It says sign-ups open soon.
- **Location and hours** are shown as *Demo · details to be confirmed*. There's no directions link and no structured data.
- **Socials and delivery apps** aren't linked. Socials are marked "coming soon".
- **Photography** is AI-generated concept imagery. See `docs/assets.md`.

## Deploy (Vercel)
This is a static Vite app: framework preset **Vite**, build `npm run build`, output `dist`. `public/404.html` is served for unknown routes.
